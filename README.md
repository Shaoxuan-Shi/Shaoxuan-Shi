# Shaoxuan Shi

Data Science and Business Analytics graduate focused on turning operational and commercial questions into reproducible analyses, decision-ready dashboards, and practical recommendations.

## Featured projects

### [Amsterdam Outdoor Advertising Location Intelligence](https://github.com/Shaoxuan-Shi/ai-location-intelligence-ads)

An end-to-end location intelligence product for screening outdoor advertising sites in Amsterdam. It combines public pedestrian counts, geospatial context, uncertainty evidence, and campaign-specific ranking in an interactive dashboard.

**Built with:** Python, geospatial analysis, robust regression, validation, and data visualization  
**Try it:** [Live interactive dashboard](https://shaoxuan-shi.github.io/ai-location-intelligence-ads/)

### [Dynamic Crypto Network Forecasting](https://github.com/Shaoxuan-Shi/crypto-network-forecasting)

A reproducible time-series research pipeline testing whether sparse cross-asset network signals improve next-hour cryptocurrency return-direction forecasts beyond lagged-return benchmarks.

**Built with:** R, Python, sparse VAR, LASSO, random forest, XGBoost, and block-bootstrap evaluation
